# 基于树莓派的物联网实验与智能鱼缸系统

> 西南石油大学 · 物联网工程 · 《物联网信息感知技术》课程小组项目
> 项目组长：张雪晴；组员：周锦华、王轩

基于树莓派完成的四个物联网实验，涵盖 GPIO/PWM 外设驱动、I2C/SPI 传感器采集、多线程系统调度与华为云 IoT 平台远程接入。**演示视频与运行效果见本仓库 `videos/` 目录，可在浏览器中直接打开 `index.html` 在线观看。**

## 实验内容

| 实验 | 内容 | 技术要点 |
|---|---|---|
| 实验一 | 开发环境搭建与 LED 灯控制 | 树莓派 GPIO、Final Shell / VNC 远程接入 |
| 实验二 | 物联网传感器感知 | I2C（BH1750 光照）、SPI + MCP3008 ADC（液面传感器） |
| 实验三 | 物联网外部设备驱动 | GPIO、PWM 亮度调节、步进电机脉冲控制、多线程 |
| 实验四 | 物联网综合应用：智能鱼缸系统 | 多传感器采集 + 多执行器联动控制 + 华为云 IoT（MQTT）远程监控与命令下发 |

## 功能特性

- **多传感器采集**：光照强度（BH1750，I2C）、液位（MCP3008 ADC，SPI）、水温（温度传感器）
- **多执行器控制**：LED（PWM 十级亮度）、步进电机（正反转 / 90° 角度，模拟水龙头）、加热器、蜂鸣器
- **自动联动控制**：光照不足自动补光、液位过低补水 / 过高排水、水温偏离设定自动加热，参数超限触发蜂鸣器报警
- **多线程并行调度**：三个感知-控制任务以线程并行运行，通过全局状态变量协调线程间数据共享
- **物联网远程接入**：基于 MQTT 协议将系统状态上报华为云 IoT 平台，支持远程监控与平台下发命令的远程控制

## 硬件清单

- 树莓派（主控）
- 光照传感器 BH1750（I2C 接口）
- 液面传感器 + 模数转换芯片 MCP3008（SPI 接口）
- 温度传感器与加热器
- LED、步进电机（ULN2003 驱动）、蜂鸣器
- 面包板、杜邦线、电阻等

## 运行说明

### 环境依赖

- 树莓派（Raspberry Pi OS）与 Python 3
- `RPi.GPIO`、`smbus`（I2C）、`spidev`（SPI）等库
- 华为云 IoT 设备接入 SDK（`IoT_device`，实验四）

### 华为云 IoT 凭据（实验四）

代码通过环境变量读取华为云 IoT 设备凭据，不包含任何真实密钥：

```bash
export IOT_SERVER_IP='<你的华为云 IoTDA 接入地址>'
export IOT_DEVICE_ID='<你的设备 ID>'
export IOT_SECRET='<你的设备密钥>'
```

> ⚠️ 请勿将真实设备凭据提交到代码仓库。
